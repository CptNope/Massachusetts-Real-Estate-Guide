## 🚀 How It Works:

### 1. Add Contacts:
```
Click "+ Add Contact"
Enter: Name, Email, Phone, Tags
Save → Contact added to CRM
```

### 2. Create Campaign:
```
Select contacts (checkboxes)
Choose template or write custom
Click AI button for auto-generation
Review & edit email
```

### 3. Personalize:
```
AI inserts {{firstName}} etc.
System replaces on send with real data
Each contact gets personalized email
```

### 4. Send:
```
Click "Send Campaign"
Email sent to all selected contacts
Campaign saved to history
+100 XP reward!
```
