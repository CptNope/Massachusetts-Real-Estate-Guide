## Overview

## 🎯 Practice Scenarios & Challenges

### Scenario 1: Basic Residential CMA ⭐ **BEGINNER**
**Objective:** Complete your first CMA using 3 comparable properties

**Pre-loaded Data:**
- Subject: 3 bed, 2 bath, 1,800 sqft, garage, good condition, 10 years old
- Comp 1: $425,000 | 3 bed, 2 bath, 1,750 sqft
- Comp 2: $440,000 | 3 bed, 2.5 bath, 1,900 sqft
- Comp 3: $415,000 | 3 bed, 1.5 bath, 1,650 sqft

**Learning Goals:**
- Enter property data correctly
- Calculate basic adjustments
- Understand average adjusted value
- Generate a report

**Success Criteria:**
- All 3 comps entered
- Adjusted value within ±$10,000 of expected range
- Report generated

**XP Reward:** 50 XP
**Achievement Unlocked:** "First CMA Complete" 🎯

---

### Scenario 2: Condition Adjustments ⭐⭐ **INTERMEDIATE**
**Objective:** Master condition-based adjustments

**Challenge:** Properties with varying conditions (Poor to Excellent)

**Learning Goals:**
- Understand condition impact on value
- Apply condition multipliers correctly
- Balance multiple adjustment factors

**Success Criteria:**
- Proper condition adjustments
- Recognizes when to increase/decrease condition values
- Final value within target range

**XP Reward:** 75 XP
**Achievement Unlocked:** "Condition Expert" 📊

---

### Scenario 3: Days on Market Analysis ⭐⭐ **INTERMEDIATE**
**Objective:** Factor in market timing

**Challenge:** Comps with DOM ranging from 10 to 90 days

**Learning Goals:**
- Understand DOM's effect on value
- Identify overpriced properties
- Market dynamics interpretation

**Success Criteria:**
- Correct DOM penalty application
- Can explain why long DOM matters
- Adjusted values reflect market timing

**XP Reward:** 75 XP
**Achievement Unlocked:** "Market Timer" ⏰

---

### Scenario 4: Urban vs. Suburban Analysis ⭐⭐⭐ **ADVANCED**
**Objective:** Understand location-based value differences

**Challenge:** Compare Boston property to Worcester property

**Learning Goals:**
- Adjust per-sqft values by market
- Understand urban vs. suburban pricing
- Location premium calculations

**Success Criteria:**
- Uses appropriate adjustment values for each market
- Recognizes 2-3x difference in per-sqft values
- Can explain reasoning

**XP Reward:** 100 XP
**Achievement Unlocked:** "Market Specialist" 🏙️

---

### Scenario 5: Complex Multi-Factor Analysis ⭐⭐⭐ **ADVANCED**
**Objective:** Handle properties with significant differences

**Challenge:** Subject and comps vary across ALL factors

**Learning Goals:**
- Complex adjustment calculations
- Weighting multiple factors
- Professional judgment

**Success Criteria:**
- Handles 5+ adjustment factors
- Final value logical given inputs
- Can defend valuation reasoning

**XP Reward:** 150 XP
**Achievement Unlocked:** "CMA Master" 🎓

---

### Scenario 6: Real-World Challenge ⭐⭐⭐⭐ **EXPERT**
**Objective:** Complete CMA with self-gathered data

**Challenge:** Student finds real property and gathers ALL data themselves

**Learning Goals:**
- Use assessor databases
- Verify sale prices
- Complete workflow start-to-finish
- Professional presentation

**Success Criteria:**
- Uses at least 3 real data sources
- Verifies data accuracy
- Creates professional report
- Within 5% of actual market value (if known)

**XP Reward:** 250 XP
**Achievement Unlocked:** "Real Estate Analyst" 💼

## 📝 Notes for Implementation

### Design Principles:
- **Fun but Educational:** Games must teach real skills
- **Non-Intrusive:** Optional - users can skip gamification
- **Progress-Based:** Rewards skill development, not just time
- **Achievable:** All students should reach some achievements
- **Challenging:** Top achievements require real mastery

### Avoid:
- ❌ Pay-to-win mechanics
- ❌ Misleading difficulty curves
- ❌ Overly competitive (discourages beginners)
- ❌ Too many notifications (annoying)
- ❌ Complexity that confuses educational goals
